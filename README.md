# 📸 Pixel Image Gallery

A beautiful, responsive image gallery built using HTML, CSS, and JavaScript.

## ✨ Features

- Responsive image gallery layout
- Category filters: Nature, Architecture, Wildlife
- Full-screen lightbox image viewer
- Previous and Next image navigation
- Keyboard navigation using arrow keys
- Escape key to close the lightbox
- Smooth hover effects and animations
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Unsplash for photographs
